# Conference Guidelines (ICLR / FAccT / COMPASS Track)

## Submission deadline

November 1, 2026.

The Literature Review Agent should derive `cutoff_date = 2026-11-01` from
this deadline. Papers published on or before this date may be cited as prior baselines.

## Page limit

The main paper is limited to **9 pages** of text, excluding references and appendices.

## Mandatory sections

The submission MUST contain, in this order:

1. Abstract (single paragraph, ~150-250 words)
2. Introduction
3. Related Work
4. Methodology
5. Experiments
6. Conclusion
7. References

## Formatting rules

- Use `\documentclass{article}` (the bundled `template.tex` is the canonical skeleton)
- Citations via `\cite{...}` commands
- Figures saved at 300 DPI minimum
- Tables use the booktabs package (`\toprule`, `\midrule`, `\bottomrule`)
- All figures and tables MUST appear before the Conclusion section
- Anonymized for double-blind review during automated checks: do not include author emails or institutional affiliations in the draft title block

## Topic scope

Submissions on machine learning methodology, computer vision benchmarks, document intelligence, optical character recognition, vision-language models, and high-stakes civic/electoral integrity auditing in developing regions.

## Review criteria

Reviewers will assess: scientific soundness, empirical rigor, clarity, significance for real-world deployment, and mathematical reproducibility.
